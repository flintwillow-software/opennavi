# specs-render

> Render the full spec as one ordered document. The spec tree is storage; the render is the law.

## Steps

### 1. Walk the tree in numeric order

For each `docs/specs/NN-component/` directory (sorted by NN):

1. Read `README.md` — include the component description and feature table. Strip frontmatter.
2. For each `NN-feature.md` file (sorted by NN), strip frontmatter and append.

### 2. Assemble the document

```
# Specification: <project name>

> Generated by specs-render on YYYY-MM-DD. Source: docs/specs/

## 00 Component Name

[component README content]

### 00.00 Feature Name

[feature file content]

### 00.01 Feature Name

[feature file content]

## 01 Component Name
...
```

### 3. Handle token budget

- If the full document exceeds ~3000 tokens, render the index first (README table) and page sections on demand.
- Each feature file is ≤ 2000 tokens per the template convention, so the holistic read degrades gracefully.
