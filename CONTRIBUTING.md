# Contributing

Thank you for your interest in contributing! This document covers the basics of how to work within this project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone git@github.com:<username>/<repo>.git`
3. Create a branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Commit following [conventional commits](https://www.conventionalcommits.org/):
   ```
   feat: add new feature
   fix: resolve bug #123
   docs: update README
   chore: update dependencies
   ```
6. Push and open a pull request

## Pull Requests

- PRs should be linked to an issue or epic
- All checks must pass before merging
- At least one review is required
- Use the [PR template](.github/PULL_REQUEST_TEMPLATE.md)

## Code Standards

- Follow the project's style guide (linting/formatting configs in the repo)
- Write tests for new functionality
- Update documentation as needed

## Branching

- `main` — always deployable
- `feature/<name>` — new features
- `fix/<name>` — bug fixes
- `chore/<name>` — maintenance

## Questions?

Open a discussion or reach out to the team.
