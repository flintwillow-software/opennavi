# OpenNAVI

A platform for building **navis** — self-contained AI agent binaries distributed as single signed executable files.

## Documentation

| Resource | Description |
|----------|-------------|
| [Architecture Specs](./docs/specs/README.md) | Full OpenNavi architecture specs organized by feature — navi definition, agent runtime, multi-agent, messaging, operations, and more |

| [Cleanroom Specs](./docs/README.md) | Additional design specs for the pi-mono rewrite and Hermes-inspired extended features |

## Getting Started

Define a navi, run the builder, and get a signed binary. See the [navi-core specs](./docs/specs/00-navi-core/README.md) for the definition format and build toolchain.
